# 架构与数据流

Pulse 全身集总模型输出系统动脉压（mmHg）和时间（s），作为局部入口边界假设。PPG 2R1C 模型产生局部压力（mmHg）、容积（mL）和支路流量（mL/s）。固定采样体积内的血液分数改变线性混合吸收系数（1/mm），随后 MCX/PMCX 在显式体素几何、材料参数和有限面积探测器下运行光子传输。PPG 使用 AC/DC、吸收重加权和独立种子直接仿真对照分析结果。

本项目未实现指端传播、波反射、全身负载变化或压力驱动组织几何变化。局部流量不是全身心输出量。Photon replay 给出指定基准点的局部光学 Jacobian，不代表组织实际贡献比例。示例输入是工程假设，输出都是模拟数据。详情见 implementation.md、sources.md 和 acceptance.md。
